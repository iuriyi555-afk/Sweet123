This Privacy Policy explains what data Sweet Translator processes, why it is processed, and how long it is kept.

1) Account and sign-in

  • The app uses Google Sign-In (OAuth) and Firebase Authentication.
  • We use a Firebase user identifier (UID) to provide app functionality.
  • The app may store a display name you enter in the app.

2) Chat data

  • Chat messages you send/receive are synced via Firebase/Firestore to provide chat functionality.
  • Message metadata (e.g., timestamps, sender/receiver identifiers inside the chat) may be stored to keep the chat working.

3) Audio and AI processing

  • The app does not store audio recordings as files by default.
  • If cloud features (speech/translation/AI) are enabled, audio and/or recognized text may be transmitted to cloud services for processing.

4) Data retention

  • Chat retention: chat messages are designed to be short-lived. Messages are marked to expire in about 3 days.
  • History limit: the app also keeps only the most recent ~50 messages per chat (older messages are removed on a best-effort basis).
  • Note: deletion can be delayed if the app is not opened for a long time or the device is offline.

5) Security

  • Data transmitted to cloud services uses standard encryption (HTTPS/TLS).

6) Your choices

  • You can request account/data deletion: Delete account / data.
  • You can stop using the app at any time (uninstall).

7) Contact

For privacy questions, contact: sweethelp123@gmail.com

Эта Политика конфиденциальности объясняет, какие данные обрабатывает Sweet Translator, зачем и как долго они хранятся.

1) Аккаунт и вход

  • Приложение использует вход через Google (OAuth) и Firebase Authentication.
  • Для работы приложения используется идентификатор пользователя Firebase (UID).
  • В приложении может храниться имя, которое вы укажете (display name).

2) Данные чата

  • Сообщения чата синхронизируются через Firebase/Firestore для работы функции чата.
  • Может сохраняться служебная информация (например, время/отправитель/получатель внутри чата), чтобы чат работал корректно.

3) Голос и AI/облако

  • Приложение по умолчанию не хранит аудиозаписи как файлы.
  • Если включены облачные функции (речь/перевод/AI), аудио и/или распознанный текст могут передаваться в облачные сервисы для обработки.

4) Срок хранения данных

  • Чат: сообщения рассчитаны на короткое хранение и помечаются на удаление примерно через 3 дня.
  • Лимит истории: хранится только ~50 последних сообщений на чат (более старые удаляются best-effort).
  • Важно: удаление может задержаться, если приложение долго не запускали или устройство офлайн.

5) Безопасность

  • Передача данных в облако выполняется по защищённому соединению (HTTPS/TLS).

6) Ваши действия

  • Запросить удаление аккаунта/данных: Удаление аккаунта / данных.
  • Можно прекратить использование приложения в любой момент (удалить приложение).

Политика конфиденциальности Sweet Translator

Дата вступления в силу: 2026-01-23

1. Общие положения

1.1. Настоящая Политика описывает, какие данные собираются, как они используются и защищаются в приложении Sweet Translator (далее — «Приложение»).

1.2. Используя Приложение, вы соглашаетесь с условиями этой Политики.

2. Сбор данных

2.1. Приложение не отправляет историю чата на серверы.

2.2. Аудио не хранится локально и не сохраняется в Приложении.

2.3. Для распознавания и перевода речи используется облачный сервис AI-ассистента; аудио может временно передаваться в облако для обработки, но не сохраняется.

3. Использование данных

3.1. Аудио используется исключительно для обработки запроса пользователя в облачном сервисе.

3.2. Данные не используются для аналитики, таргетинга или передачи третьим лицам.

4. Хранение данных

4.1. Приложение не хранит аудио и историю чатов.

4.2. Обработка данных происходит временно в облачном сервисе только для выполнения функций приложения.

5. Права пользователей

5.1. Пользователь вправе запросить удаление любых личных данных, если таковые будут собраны (например, при локальном кэшировании).

5.2. Пользователь может отключить использование облачного распознавания, ограничив функциональность Приложения.

6. Безопасность

6.1. Приложение и облачные сервисы используют стандартные меры безопасности для защиты данных при передаче.

6.2. Так как данные не хранятся, риски утечки сведены к минимуму.

7. Изменения Политики конфиденциальности

7.1. Приложение может обновлять настоящую Политику.

7.2. О любых изменениях пользователи будут уведомлены через обновление Приложения.

8. Контакты

8.1. По вопросам конфиденциальности и обработки данных: sweethelp123@gmail.com.

Sweet Translator Privacy Policy

Effective date: 2026-01-23

1. General

1.1. This Privacy Policy explains what data is processed in Sweet Translator (the “App”), how it is used, and how it is protected.

1.2. By using the App, you agree to this Policy.

2. Data processing

2.1. The App does not send your chat history to our servers.

2.2. The App does not store audio locally and does not save audio within the App.

2.3. When AI Assistant mode is enabled, speech recognition and translation are performed via a cloud service. Audio may be temporarily transmitted to the cloud for processing and is not stored by the App.

3. Use of data

3.1. Audio is used solely to fulfill the user’s request (speech recognition/translation) via the cloud service.

3.2. The App does not use your data for advertising, tracking, or selling data to third parties.

4. Data retention

4.1. The App does not retain audio and does not retain chat history.

4.2. Any cloud processing is temporary and only for providing the App’s functionality.

5. User choices

5.1. You may request deletion of any personal data if it is ever collected (for example, in local cache scenarios).

5.2. You can disable cloud/AI processing features, which may limit certain App functionality.

6. Security

6.1. The App and cloud services use standard security measures to protect data in transit.

6.2. Since the App does not store data, risks are minimized.

7. Changes to this Policy

7.1. We may update this Privacy Policy from time to time.

7.2. Material changes will be communicated through App updates.

8. Contact

8.1. For privacy-related questions: sweethelp123@gmail.com.

This policy explains what data Sweet Translator processes, why we process it, and how long we keep it.

What data the app processes

  • Account: when you sign in with Google, we receive and use a Firebase user identifier (UID). You may also set a display name inside the app.
  • Chat messages: messages you send/receive are synced via Firebase/Firestore to provide chat functionality.
  • Diagnostics: basic technical logs may be used to troubleshoot issues when you contact support.

How we use data

  • Provide chat sync and message delivery.
  • Provide translation features (when enabled).
  • Support and troubleshooting (upon user request).

Data retention (how long we keep data)

  • Chat messages: the app is designed to keep chat history limited. Messages are marked to expire in about 3 days and the app also keeps only the most recent ~50 messages per chat (older messages are removed on a best-effort basis).
  • Note: deletion can be delayed if the app is not opened for a long time or the device is offline.

Security

  • Network traffic uses standard encryption (HTTPS/TLS) when communicating with cloud services.

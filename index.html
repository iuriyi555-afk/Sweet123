Политика конфиденциальности Sweet Translator

Дата вступления в силу: 2026-01-23

  1. Общие положения
    1. Настоящая Политика описывает, какие данные обрабатываются в Sweet Translator (далее — «Приложение»), как они используются и как защищаются.
    2. Используя Приложение, вы соглашаетесь с условиями этой Политики.
  2. Сбор и обработка данных
    1. Сообщения чата (режим Chat). В режиме чата Приложение сохраняет и синхронизирует сообщения между устройствами через облачную базу данных Firebase/Firestore. Сообщения могут включать введённый текст, переведённый текст, метки времени, а также технические идентификаторы чата/сообщения, необходимые для работы синхронизации.
    2. Аудио. Приложение не сохраняет аудиозаписи локально и не хранит аудио в Приложении.
    3. Облачное распознавание/перевод (AI/Cloud). При включённом облачном распознавании и/или переводе голосовые данные и/или распознанный текст могут временно передаваться в облачные сервисы для обработки (распознавания/перевода). Приложение не сохраняет аудио. Политика хранения и обработки данных у сторонних провайдеров регулируется их условиями.
  3. Использование данных
    1. Данные используются только для предоставления функций Приложения: синхронизация чата между устройствами, отображение сообщений, выполнение распознавания речи и перевода по запросу пользователя.
    2. Приложение не использует данные для персонализированной рекламы и не продаёт данные третьим лицам.
  4. Хранение данных
    1. Сообщения чата. Сообщения чата могут храниться в Firebase/Firestore до удаления пользователем (если такая функция доступна в Приложении) и/или до выполнения запроса на удаление через поддержку.
    2. Локальные данные. На устройстве могут храниться технические данные и кэш (например, настройки приложения и локальные счётчики непрочитанных), необходимые для корректной работы.
    3. Аудио. Аудиозаписи не сохраняются в Приложении.
  5. Права пользователей
    1. Пользователь может запросить удаление данных, связанных с использованием Приложения, написав на адрес поддержки: sweethelp123@gmail.com.
    2. Пользователь может отключить облачное распознавание/перевод (если такая опция доступна), что может ограничить функциональность Приложения.
  6. Безопасность
    1. Приложение и используемые облачные сервисы применяют стандартные меры безопасности для защиты данных при передаче.
    2. Риски утечки снижаются за счёт отсутствия хранения аудио в Приложении, однако при использовании облачных сервисов обработка может выполняться на стороне провайдера.
  7. Изменения Политики конфиденциальности
    1. Приложение может обновлять настоящую Политику время от времени.
    2. Существенные изменения могут быть сообщены через обновления Приложения и/или обновление этой страницы.
  8. Контакты
    1. По вопросам конфиденциальности и обработки данных: sweethelp123@gmail.com
    2. Разработчик: Iurii Shcherbinin
Примечание: Если в текущей версии Приложения нет кнопки/функции удаления сообщений, удаление выполняется через обращение в поддержку по email.

Sweet Translator Privacy Policy

Effective date: 2026-01-23

  1. General
    1. This Privacy Policy explains what data is processed in Sweet Translator (the “App”), how it is used, and how it is protected.
    2. By using the App, you agree to this Policy.
  2. Data processing
    1. Chat messages (Chat mode). In Chat mode, the App stores and syncs messages between devices using a cloud database Firebase/Firestore. Messages may include entered text, translated text, timestamps, and technical identifiers required for syncing and app functionality.
    2. Audio. The App does not store audio recordings locally and does not save audio within the App.
    3. Cloud speech recognition/translation (AI/Cloud). When cloud speech recognition and/or translation is enabled, voice data and/or recognized text may be temporarily transmitted to cloud services for processing (speech recognition/translation). The App does not store audio. Third-party handling/retention is governed by their own policies.
  3. Use of data
    1. Data is used only to provide the App’s functionality: chat synchronization between devices, displaying messages, and performing speech recognition/translation at the user’s request.
    2. The App does not use data for personalized advertising and does not sell data to third parties.
  4. Data retention
    1. Chat messages. Chat messages may be stored in Firebase/Firestore until the user deletes them (if such a feature is available in the App) and/or until a deletion request is processed via support.
    2. Local data. The App may store technical data and local cache on the device (e.g., app settings and unread counters) required for proper operation.
    3. Audio. Audio recordings are not stored in the App.
  5. User choices
    1. You may request deletion of data related to your use of the App by contacting support: sweethelp123@gmail.com.
    2. You may disable cloud speech/translation features (if available), which may limit certain functionality.
  6. Security
    1. The App and related cloud services use standard security measures to protect data in transit.
    2. Risks are reduced because the App does not store audio; however, cloud processing may be performed by third-party providers.
  7. Changes to this Policy
    1. We may update this Privacy Policy from time to time.
    2. Material changes may be communicated via App updates and/or updates to this page.
  8. Contact
    1. For privacy-related questions: sweethelp123@gmail.com
    2. Developer: Iurii Shcherbinin
Note: If the current App version does not provide an in-app delete feature, deletions are handled via email request to support.
